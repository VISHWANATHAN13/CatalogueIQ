# Fashion Attribute Guide

## Core Attributes

Use the following attributes when answering fashion questions:

- Size
- Fit
- Material
- Color
- Sleeve length
- Closure
- Care instructions
- Occasion

## Fit

Slim, regular, straight, relaxed, and oversized are different
fit descriptions.

Do not infer one fit from another.

## Material

Use the catalogue material field as the source of truth.

For example, "cotton blend" must not be rewritten as
"100% cotton".

## Recommendations

For fashion recommendations, satisfy explicit:

- Size
- Budget
- Material
- Occasion

constraints first.

Rating should normally be treated as a secondary preference
unless the shopper explicitly makes it a hard requirement.
